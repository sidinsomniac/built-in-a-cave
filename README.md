# Built in a Cave

*"Tony Stark was able to build this in a cave, with a box of scraps."* Now it's your turn: an Iron Man–themed game that takes you from "what happens when I type a URL?" to passing senior and engineering-lead loops in:

- **🛠 Machine coding:** real React and TypeScript in the browser, against hidden tests, accessibility checks and a timer.
- **🖥 Front-end system design:** RADIO rounds on a component blueprint with a live performance lab. News feed, autocomplete, Pinterest, chat, Google Docs, Netflix player and more.
- **🏗 Backend system design:** a drag-and-wire architecture canvas with a live traffic and failure simulation. URL shortener, rate limiter, WhatsApp, YouTube, Uber, ticket booking, payments and more.

Every answer is **built, not written**, and lands in a zone: 🟢 Optimal, 🔵 Solid, 🟡 Risky or 🔴 Failing. Rhodey's audit follows, itemised. JARVIS, your mentor, only ever asks questions.

**Status:** the engine slice is playable:
- a Phase 1 lesson (DNS);
- a Workshop mission (debounce and throttle, run against hidden tests in a sandbox);
- the **URL shortener** case through all seven stations, at three support levels.

See [docs/HANDOFF.md](docs/HANDOFF.md) for what's next, and [docs/curriculum.md](docs/curriculum.md) for the six Phases.

## Run it
```bash
npm install
npm run dev
```

Tests: `npm test` (unit), `npm run validate-content` (proves every exercise and case), `npm run e2e` (Playwright).
