# Clients and servers

- **Client:** the asker (browser, phone app). **Server:** the answerer (a computer running a listening program).
- **Request → response:** every interaction is a conversation of these.
- **Database:** where a server keeps data so it survives restarts. The usual chain: client → server → database.
- **Where work happens:** instant, harmless work on the client; secrets, money and big data on the server; validation on **both**.
- **Never trust the client alone:** it's under the user's control.
